# AzureSDK::LocalUserProperties

## Properties

| Name | Type | Description | Notes |
| ---- | ---- | ----------- | ----- |
| **permission_scopes** | [**Array&lt;PermissionScope&gt;**](PermissionScope.md) | The permission scopes of the local user. | [optional] |
| **home_directory** | **String** | Optional, local user home directory. | [optional] |
| **ssh_authorized_keys** | [**Array&lt;SshPublicKey&gt;**](SshPublicKey.md) | Optional, local user ssh authorized keys for SFTP. | [optional] |
| **sid** | **String** | A unique Security Identifier that is generated by the server. | [optional][readonly] |
| **has_shared_key** | **Boolean** | Indicates whether shared key exists. Set it to false to remove existing shared key. | [optional] |
| **has_ssh_key** | **Boolean** | Indicates whether ssh key exists. Set it to false to remove existing SSH key. | [optional] |
| **has_ssh_password** | **Boolean** | Indicates whether ssh password exists. Set it to false to remove existing SSH password. | [optional] |
| **user_id** | **Integer** | A unique Identifier that is generated by the server. | [optional][readonly] |
| **group_id** | **Integer** | An identifier for associating a group of users. | [optional] |
| **allow_acl_authorization** | **Boolean** | Indicates whether ACL authorization is allowed for this user. Set it to false to disallow using ACL authorization. | [optional] |
| **extended_groups** | **Array&lt;Integer&gt;** | Supplementary group membership. Only applicable for local users enabled for NFSv3 access. | [optional] |
| **is_nfsv3_enabled** | **Boolean** | Indicates if the local user is enabled for access with NFSv3 protocol. | [optional] |
